# ✨ cvlaunch — Editor de Currículos Inteligente

🔗 [Acesse agora](https://abre.ai/cvlaunch)

O **cvlaunch** é uma plataforma interativa para criação de currículos profissionais. Com uma interface moderna e recursos avançados, você pode construir um currículo que conta sua história, destaca suas habilidades e impressiona recrutadores.

---

## 🛠️ Funcionalidades

- Autenticação com Google ou GitHub
- Editor em tempo real para personalização completa
- Armazenamento seguro dos currículos no banco de dados
- Geração de conteúdo com Inteligência Artificial (sugestões e otimizações)
- Exportação para PDF com layout preservado
- Funcionalidades premium com pagamento via Stripe

---

## ⚙️ Tecnologias Utilizadas

- **Next.js 14** — Framework moderno baseado em React
- **TypeScript** — Tipagem estática para maior confiabilidade
- **Auth.js (NextAuth)** — Autenticação segura e flexível
- **shadcn/ui** — Componentes de interface reutilizáveis
- **Tailwind CSS** — Estilização rápida e responsiva
- **Drizzle ORM** — Gerenciamento eficiente de banco de dados
- **Puppeteer** — Geração de PDFs automatizada
- **Stripe** — Integração de pagamentos
- **TanStack Query** — Sincronização de dados assíncronos
- **React Hook Form** — Gerenciamento de formulários
- **OpenAI** — Geração inteligente de conteúdo
